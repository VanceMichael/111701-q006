# 供水服务窗口采集服务

这是一个用于供水服务窗口的本地数据采集与归档服务。当前版本从仓库自带的合成来源记录读取一页数据，经过字段规整后写入进程内目录；来源内容和规整后的记录保留独立边界，便于在不访问外部系统的情况下复现采集过程。

## 更新与撤销语义

来源页可以是**部分页面**：只包含运营方这次改动的街区。

- 页面上出现的街区按较新的修订号/观察时间合并，未出现的街区保留原有安排。
- 旧缓存整页回放不会覆盖较新的记录，也不会复活已撤销的地点。
- 街区级撤销（`state: "revoked"`、`status`、`revoked: true`、`revokedAt` 等，或页面上的 `revokedIds`）会留下墓碑，该街区从居民查询结果中消失。
- 整份公告撤销（`revoked: true`、`announcementState`、嵌套的 `announcement` 等）会关闭该来源的全部街区；未列出撤销名单时视为整份撤销。
- 携带 `revokedIds` 的页面只撤销名单内的街区，同页其他街区照常合并且不牵连未提及的街区。
- 只有严格更新的公告才能重新开放已撤销的街区；迟到的旧撤销不会撤销已经更新的地点。
- `RecordStore#list()` 是居民侧视图，只返回仍有效的地点；`RecordStore#listAll()` 保留撤销记录供运营审计。

## 运行

需要 Node.js 20 或更高版本，不需要安装第三方依赖。

```sh
npm test
npm run build
node src/pipeline.mjs
```

测试使用项目内的合成记录；执行不需要网络、凭据或外部服务。
